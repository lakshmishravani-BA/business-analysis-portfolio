# Customer Complaint Analysis Dashboard

## Overview

An Excel-based Business Analysis dashboard developed as part of a simulated customer complaint analysis case study.

The dashboard converts complaint data into actionable business insights by analyzing complaint volume, resolution performance, repeat contacts, complaint channels, monthly trends, and potential root causes.

> **Portfolio project:** The dataset and business scenario are simulated and are not presented as real client work.

## Dashboard Objectives

The dashboard was designed to help business stakeholders:

* Monitor overall complaint volume and key performance indicators.
* Identify complaint categories with the highest volume.
* Compare complaint volume across communication channels.
* Evaluate resolution performance by priority.
* Monitor complaint trends over time.
* Identify the most common potential root causes.
* Highlight areas where process improvement may be required.

## Key Performance Indicators

The dashboard tracks:

| KPI                      | Description                                                |
| ------------------------ | ---------------------------------------------------------- |
| Total Complaints         | Total number of complaints analyzed                        |
| Average Resolution Time  | Average time required to resolve complaints                |
| High-Priority Complaints | Number of complaints classified as high priority           |
| Repeat Contact Rate      | Percentage of complaints involving repeat customer contact |
| Resolved Complaints      | Number of complaints marked as resolved                    |

## Dashboard Analysis

### 1. Complaints by Category

Compares complaint volume across categories such as:

* Delivery
* Billing
* Product Quality
* Refund
* Account

This helps identify which complaint categories require the greatest management attention.

### 2. Complaints by Channel

Analyzes complaint volume across:

* Email
* Phone
* Web
* Chat

This provides visibility into how customers are contacting the organization.

### 3. Average Resolution Time by Priority

Compares average resolution time for:

* High-priority complaints
* Medium-priority complaints
* Low-priority complaints

This helps identify whether higher-priority issues require significantly more time to resolve.

### 4. Monthly Complaint Trend

Tracks complaint volume across the available reporting period to identify changes or recurring patterns over time.

### 5. Complaints by Root Cause

Summarizes potential underlying causes identified during the analysis, including:

* Delivery delays
* Incorrect invoices
* Product defects
* Refund processing delays
* Account information issues

This supports root-cause analysis and prioritization of process improvement opportunities.

## Key Findings

The underlying analysis identified several notable patterns:

* Delivery complaints represented the largest complaint category.
* Repeat contacts represented a significant proportion of complaints.
* High-priority complaints had substantially longer average resolution times than lower-priority complaints.
* Delivery delays and incorrect invoices were among the most frequent identified root causes.
* The analysis highlights opportunities to improve resolution processes and reduce recurring customer issues.

Detailed findings are documented in the project's analysis and root-cause analysis files.
